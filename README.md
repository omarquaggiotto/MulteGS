# Multe GS

Applicazione indipendente per la gestione di multe, quote e pagamenti della **GS Montecchio San Pietro – Squadra B**.

## Avvio locale

Il progetto è una PWA statica: pubblicare la cartella con un server HTTP oppure aprirla tramite il servizio di hosting scelto. Per l'accesso amministratore usare il nome utente `admin` e la password concordata separatamente.

## Servizi collegati

- Supabase dedicato al progetto `MulteGS` per autenticazione, persistenza e sincronizzazione.
- Calendario e collegamenti partita della squadra B su Tuttocampo.
- Cache offline tramite Service Worker.

Lo stemma ufficiale è incluso in `stemma-gs-montecchio-san-pietro.png`.
